H3 Reference Library guide

Save reusable references, select the ones a prompt needs, then copy their tags into your prompt list.

Typical flow Add or find a reference → Select it → Open Reference Creator → Copy the guide → Use the tags in an independently authored prompt.

Reference Library

Manage your own characters, locations, objects, clothing, music, and video references. A saved item can hold images with individual descriptions, video, audio, a voice description, and private notes. Select an item to include its tag in Reference Creator.

Images and audio are optional. A character can be visual only, voice only, or both. A voice attachment is used by the deterministic compiler only when that character speaks in the prompt.

{news_anchor} is an example of a saved tag. Use the exact tag shown on the card.

Built In Characters

Browse the built-in character catalog, search by character, actor, or show, and select the characters you need. Built-in tags carry a _BC suffix to avoid collisions with your own references.

Where available, add an image or voice attachment and edit its voice description. A built-in character can also belong to an optional collection.

RefMods

RefMods are saved .safetensors references. They may contain appearance, voice, or both. Browse, import, select, export, create, and edit them on the RefMods page. Selected RefMods join the same Reference Creator list as other references.

For creation or editing, add pictures, video sections, or audio, then choose Full reference or Compressed + refinement. Encoding uses the video and audio VAEs connected to SKEBA RefMod Studio Create / Edit in the open workflow. Saving does not automatically insert the RefMod into a prompt.

Use the exact RefMod tag shown in the library, for example {celestial_rm}.

Reference Creator

This tab gathers your selected items from Reference Library, Built In Characters, and RefMods into one copyable guide. You can remove one selection here or clear them all. Hide details produces a shorter guide when the full descriptions would distract your prompt-writing tool.

The guide helps you write prompts; it does not run generation or change saved assets. Copy it, then write each clip’s subject_definitions: and shot text with the needed tags.

Prompt rule Each |-separated prompt is compiled independently. Repeat every needed tag or temporary definition in that prompt’s subject_definitions:. A visual character does not automatically contribute its voice; include a clear speaking event if you want its attached voice considered.
