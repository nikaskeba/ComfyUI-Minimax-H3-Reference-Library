# Multiple reference images and private notes

Saved Reference Library items can include multiple images, each with its own description. The editor shows a small main-image preview and a horizontally scrolling strip of additional images, where each can be described or removed. The overview shows the image count inside the Image badge. If the main image is removed, the first remaining image becomes the preview.

H3 Tagged Reference Prompt automatically loads these images in order. In deterministic mode, one subject can reference several numbered pictures without duplicating the subject or its voice. Additional images count toward the existing limit of nine ordinary reference images per prompt. Both direct image outputs and deferred reference bundles support them; existing single-image records continue working unchanged.

The item editor also includes **Notes (Reference Creator only)**. Notes appear with selected items in Reference Creator for your own reminders. They are excluded from generated prompts, mapping output, and the copied reference guide.

These controls apply to saved Reference Library records. Built In Characters and RefMod asset editors retain their existing controls.

Choose **Clothing** for image-only outfit references such as a hat or suit. A saved clothing tag such as `{blue_suit}` compiles as one visual subject with its attached images numbered together. It does not create a voice or audio reference.
