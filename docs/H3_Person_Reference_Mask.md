# Reference subject mask (two tracks)

**SKEBA Reference Subject Mask (2 Tracks)** outputs two independent video-length `MASK` batches. Track 1 uses `face_reference`; optional track 2 uses `reference_2` and is off by default. Both tracks share the human detector's frame scan. Existing workflows keep their first three output socket positions: mask, preview, status. The appended outputs are `mask_2` and `frame_data_json`. The preview shows track 1 in green and track 2 in orange. The node does not generate or change video or audio.

For a human track, connect a clear face photo and select **whole person**, **face**, or **head**. Whole person uses the installed `models/insightface/models/buffalo_l` pack and `models/ultralytics/segm/person_yolov8m-seg.pt`. Face and head additionally use FaceXLib ParseNet at `models/facedetection/parsing_parsenet.pth`. Face includes skin and facial features but excludes hair; head includes hair and hats. If the face cannot be reliably located in a frame, face/head modes leave that frame empty rather than inventing a region.

For a dog, dinosaur, or other nonhuman subject, set that track's kind to **object**. Supply a seed `MASK` (one frame or a full-length batch) or `seed_box` JSON such as `{"x":100,"y":80,"width":250,"height":300}` at `seed_frame`. The node segments a seed box with GrabCut, then propagates the mask with optical flow. A reference photo alone can seed an object when its local image features confidently match a video frame; this works best for a similar view of a textured object. When `models/ultralytics/segm/yolov8m-seg.pt` is installed, it also compares detected object masks against the photo and accepts only a distinct match. That model covers common classes such as dogs, not fictional dinosaurs; use a manual seed for them. It is not general animal identity recognition, and a photo that cannot be matched leaves the track empty. Object mode is whole-subject only.

For longer or more complex object motion, set **object_tracking** to **SAM3** and connect a native ComfyUI SAM3.1 `MODEL` loader to `sam3_model`. A manual seed mask is best for a shirt, penguin, or unusual subject; a box also works. The node tracks forward and backward from `seed_frame`. Each object track retains its own seed and output. SAM3 uses more memory and can still lose a subject during occlusion or a large appearance change. Existing workflows default to the original local tracker.

`mask_expand` grows each selected mask outward in pixels; `mask_feather` softens its edge. Start with both at zero. `identity_threshold` controls human face matching. `max_track_gap` permits brief human body tracking when a face turns away; zero requires a face match on every masked frame. Review the preview before inpainting.

Long 1080p clips can take several minutes because every frame is segmented and checked. The node reports frame progress so you can distinguish processing from a stalled server. Face/head parsing uses the GPU when available. `preview_max_side` defaults to 640 pixels to keep the inspection preview small; both mask outputs retain the source video's full resolution.

Each `MASK` batch is shaped `[frames, height, width]`. `frame_data_json` has a `track_1` and `track_2` array with one record per zero-based frame: `masked`, pixel count, coverage fraction, bounding box, and selection source (`face`, `photo`, `seed`, `track`, or `none`). It can be connected to Display Any or parsed by another node to find exactly which frames were masked. Downstream H3 latent inpainting may need conversion from pixel-frame masks to H3's video-token mask layout.
