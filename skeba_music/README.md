# Skeba Music (part of Skeba AI Nodes)

These nodes now ship inside the `h3_tag_references` package. Keep only that
custom-node folder enabled in ComfyUI. The original node IDs, menu category,
and workflow sockets are unchanged.

**SKEBA MuScriptor Transcribe Audio to MIDI** takes the same full-length audio as SheetSage and its connected ABC score. Connect SheetSage's new **beat_map** output as well: MuScriptor note times are placed against the beats SheetSage actually heard, then written on the ABC score's exact 16th-note MIDI grid. This is more accurate than using one average BPM across a song. The beat-map input is optional; old workflows retain their BPM-only behavior. The node reuses MuScriptor's installed model and transcription controls and saves a type-1 `.mid` with separate instrument tracks, tempo/meter, a saved path, `YUE2_MIDI` bytes, and final quantized `notes_json`. Use **Skip malformed** to omit broken note pairs while retaining short valid notes, or **Strict error** to stop on them. A material ABC duration mismatch prints a warning; a beat map from different-length audio is rejected. No notes are stretched to the ABC score's length. **tempo_override_bpm** controls MIDI playback tempo, while the connected beat map controls which score positions the notes occupy; leave the override at 0 when using **Skeba ABC Shared Tempo**. This node requires the separate ComfyUI-MuScriptor installation.

The supplied `workflows/tool_MuScriptor Example.json` sends SheetSage's ABC through **Skeba ABC Shared Tempo** before both **Skeba ABC to MIDI** and **SKEBA MuScriptor**, and connects SheetSage's **beat_map** directly to MuScriptor. Set the shared BPM to the song's verified constant tempo; 0 keeps SheetSage's estimate. MuScriptor's separate override stays at 0. The two MIDI outputs feed **SKEBA Combine Transcription MIDIs**, and the combined file is saved as `combined_shared_grid`. A separate `sheetsage_score` MIDI is saved for comparison. Import the MIDI tempo into Ableton and align the song's first downbeat to the score; if you change Live's tempo, warp the original audio accordingly. The beat map addresses global drift and local beat fluctuation, but it cannot tell whether MuScriptor picked the wrong individual 16th or shifted a whole drum phrase; SheetSage has no drum track to match those hits against.

**SKEBA Combine Transcription MIDIs** accepts the MIDI output of **Skeba ABC to MIDI** (fed by SheetSage's ABC) and the MIDI output of **SKEBA MuScriptor Transcribe Audio to MIDI**. Connect its output to **Skeba Save MIDI**. The result is one type-1 MIDI file with separate tracks labeled `SheetSage - ...` and `MuScriptor - ...`, so Ableton can compare, mute, or edit either transcription. SheetSage supplies the tempo and meter. **Nearest 16th** (default) snaps both models' starts and ends to that shared grid, removing small conversion offsets; **Preserve original timing** retains each model's note timing. The node preserves instrument programs and the drum channel. It does not choose which model's notes are correct or force independently detected hits to the same beat.

**SKEBA MIDI Pattern Stabilizer** accepts any `YUE2_MIDI` output. It identifies an established sequence of equally spaced note-onset groups within each track and repairs an isolated near-grid early or late onset when the shift is within `tolerance_ticks` (20 by default). It moves that note's end by the same tick count, retaining duration, pitch, and velocity. It uses absolute integer MIDI ticks, so corrections do not accumulate rounding drift. The selected subdivision sets the grid (sixteenth by default); `min_prior_intervals` controls how many regular intervals must precede a correction (three by default). Passages without a strong repeating pulse are left alone. **Correct on-grid step** is off by default; turn it on to test an isolated note placed one full subdivision early or late. That mode additionally requires the same pitch/duration pattern before and after the outlier, so it will leave many ambiguous notes unchanged. The report lists every corrected onset group; disabled mode and no-change results return the original bytes. For a combined export, place a stabilizer on each source MIDI before **SKEBA Combine Transcription MIDIs**; use **Preserve original timing** in Combine to keep the conservative corrections rather than snapping every note again. The separate `tool_MuScriptor Pattern Stabilized.json` example keeps the original SheetSage/MuScriptor exports and adds stabilized individual and combined exports.

Use the node's **Check all** control and instrument checkboxes to choose transcription groups; drums appears first. All checked retains MuScriptor's original unrestricted setting. Untick groups to constrain transcription. An empty selection is rejected so it cannot accidentally run unrestricted.

These nodes have unique `Skeba` IDs and are maintained in the Skeba AI Nodes repository. ComfyUI and ComfyUI-YuE2 updates do not overwrite this package.

Restart ComfyUI, then find **Skeba SheetSage2 Audio to ABC + MIDI** under **Skeba Music**. Connect the existing **Load Audio Encoder** (SheetSage2) and **Load Audio** nodes. The ABC output remains a list, matching the native node. Each audio batch item also produces MIDI bytes from the same transcription.

Connect `midi` to **Skeba Save MIDI** to write numbered `.mid` files under `output/Skeba Music/`. The output also works with **YuE2 MIDI File Saver** (`YUE2_MIDI`). MIDI contains separate Vocal and Ins piano tracks with original note timing, matching the transcriber's melody MIDI output. The `mode` input controls ABC chord symbols; it does not add a MIDI chord track.

**Skeba ABC to MIDI** accepts pasted ABC or a connected ABC output and converts the written score's rhythm, tempo, key signature, rests, ties, and voices to MIDI. Connect it to **Skeba Save MIDI**. For a SheetSage2 score with Vocal and Ins voices, MIDI keeps two musical tracks (plus MIDI tempo/metadata). This uses the notation timing rather than the original model's raw note timing. Conversion runs locally through Symusic's bundled abc2midi.

**Skeba MIDI to ABC** accepts a connected `YUE2_MIDI` value from MuScriptor, SheetSage, the combined transcription node, or another MIDI node and outputs editable ABC text. Connect `abc` to a text-display or save-text node. It uses Symusic's bundled `midi2abc` program locally and never changes or saves over the input MIDI. It carries tempo, meter, notes, and converter-generated voices into the notation. MIDI-to-ABC conversion is an approximation: rhythmic spelling, split voices, and some note lengths may differ from the MIDI, so keep the original MIDI when exact timing matters. No extra installation is needed beyond this pack's existing dependencies.

**Skeba Load MIDI** reads `.mid` or `.midi` files from ComfyUI's `input` or `output` folders and outputs compatible `YUE2_MIDI` bytes. Click **Upload MIDI…** to choose a file from your computer; ComfyUI copies it into `input/Skeba Music/MIDI` and selects it. Connect the loader to **Skeba MIDI to ABC**. The ⚡🅡🅞🅣🅘 MIDI Loader produces a different `MIDI` socket type and cannot connect directly. Refresh the browser after manually adding files to update the dropdown.

ABC voice names such as `name="Vocal Melody"` and `name="Ins Melody"` become MIDI track names. The converter matches each voice's decoded notes to its output track, even when a silent voice is omitted or chord symbols create extra tracks. Extra tracks are labeled `Chord-derived 1`, `Chord-derived 2`, and so on. A silent voice produces no named music track. These labels describe ABC roles; SheetSage does not identify specific instruments such as electric bass or drums. MuScriptor's instrument tracks keep their own names in the combined export.

The transcription node defaults to `abc_error_mode=skip_invalid_notes`: if a melody note collapses to zero length on the decoded rhythm grid, omit it from ABC and log the count. Valid scores use the native conversion unchanged; raw MIDI retains all original notes. Choose `strict` to report the original error instead. Other ABC errors still propagate.

Requires ComfyUI's native SheetSage2 support, `pretty_midi`, `symusic>=0.6.0`, and `mido`; install the repository-root `requirements.txt` in ComfyUI's Python environment when using a manual checkout. No separate YuE2 model loader or model download is needed. Existing workflows retain their Skeba node IDs and connections.

## YuE2 training from connected tracks

**SKEBA YuE2 Training Dataset (audio inputs)** accepts AUDIO connections, with additional sockets appearing as tracks are connected (up to 100 sockets). Each batch item is a separate training source. Connect its `dataset` output to the existing **YuE2 LoRA Trainer** and use the same native YuE2 checkpoint.

Requires **ComfyUI-YuE2-Trainer** to be installed and enabled. This adapter calls its dataset builder, preserving its 48 kHz stereo conversion, sequential clipping, short-tail handling, VAE encoding and dataset output. `default_caption` applies to every track; `none` supplies no caption. File-sidecar captions do not apply to connected tracks.

Working audio is written automatically as float WAV under `temp/yue2_connected_tracks` (or `cache_folder`). Source tensors/files are unchanged. Content-addressed working folders reuse unchanged inputs; latent caches are separated by checkpoint and clip length. `force_reencode` affects only that dataset/checkpoint/clip cache. Working files and caches remain on disk for reuse; restart ComfyUI to discover the node.
